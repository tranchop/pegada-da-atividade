# Pegada da Atividade

Calculadora em que cada patrulha escoteira estima o CO₂ equivalente da atividade do dia: transporte, lanche, energia da sede e materiais.

**App:** https://tranchop.github.io/pegada-da-atividade/

Página única em HTML/CSS/JavaScript, sem dependências de build. Para rodar localmente, abra `index.html` no navegador.
